# AI E2E QA Automation

Учебный проект системы автоматизации сквозного тестирования веб-приложений на основе методов искусственного интеллекта.

Система принимает описание требования, формирует проект тестового сценария, передает его на рецензирование инженеру QA, запускает только утвержденную версию в Playwright, сохраняет артефакты и предлагает классификацию причины сбоя. Решение об изменении ожидаемого результата или теста остается за человеком.

## Технологический стек

- TypeScript, Node.js и NestJS — управляющий API и оркестрация;
- Playwright — изолированное выполнение E2E-сценариев;
- PostgreSQL и Prisma — метаданные требований, версий, запусков и решений;
- DBeaver — проектирование и проверка модели данных;
- Docker Compose — локальная база данных;
- GitHub Actions — статическая проверка и тесты.

## Структура

```text
src/                 NestJS API и доменная логика
prisma/              физическая модель PostgreSQL
tests/               пример E2E-сценария Playwright
docs/                архитектура и правила безопасного применения ИИ
.github/workflows/    контроль качества при push и pull request
```

## Быстрый старт

1. Скопировать `.env.example` в `.env`.
2. Запустить PostgreSQL: `docker compose up -d db`.
3. Установить зависимости: `npm ci`.
4. Подготовить схему: `npm run prisma:migrate`.
5. Запустить API: `npm run start:dev`.
6. Выполнить проверки: `npm test`.

Начальная конфигурация демонстрирует границы системы и не выполняет автоматическое изменение утвержденных тестов. Подключение конкретной модели ИИ осуществляется через адаптер с журналированием версии модели и входного контекста.
